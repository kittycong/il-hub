# 업무허브

사무행정 업무를 한곳에서 보는 통합 허브 (PC·모바일 겸용, 설치 없음, 서버 없음).

메뉴 6개: **오늘 · 캘린더 · 업무 · 도구 · 예산 · 앱** (+ 설정·백업)

- **오늘**: 지난 마감·오늘·7일 안 마감, 이번 달 업무 진행률, 매일 업무, 휴가·생일
- **캘린더**: 급여·원천세·4대보험·결산·예산 등 반복 마감 자동 생성, 주말·공휴일 순연, .ics 내보내기. 문서로 확정되지 않은 날짜는 **"날짜 확인"** 표시 → 규칙 편집에서 확인하면 사라짐
- **업무**: 인수인계 문서로 만든 업무 절차 25개 + 체크리스트. "이번 달 할 일" 탭에 매월 업무와 이번 달 마감이 걸린 업무가 모임. 절차는 화면에서 직접 편집·단계 바로 추가, 새 절차 추가 가능. 예수금 관리는 재원별 금액 확인표와 진우 전표 문안(복사) 포함
- **도구**: 진우 연결(장부 엑셀 ↔ 수기 엑셀 대조, 재원×월 요약, 입력 목록) · 문서 작성(증명서, 지출결의, 출장, 구매, 기안, 휴가, 업무일지 등)
- **예산**: 재원별 잔액(담당자·내 담당), 계정별 세부(관·항·목 · 본예산/추경/집행/잔액/월별), 사업별 사용액, 미분류 계정 연결. 예산서는 엑셀에서 붙여넣기, 집행은 진우 총계정별원장 엑셀을 올려 계산 (이 기기에만 저장)
- **앱**: 카드를 누르면 **허브 안에서** 그 앱 화면이 그대로 열림 (왼쪽 "앱" 아래 목록 · 휴대폰은 위쪽 탭). 다른 메뉴에 다녀와도 입력 중인 화면 유지. ↗ 버튼은 새 탭. 업무분장·휴가·채용·출장문서·생일·빵당번 앱 모음 + 휴가·생일 데이터 자동 연동(읽기 전용)

## 배포 (GitHub Pages)
1. GitHub에서 새 저장소 `il-hub` 만들기 (Public)
2. 이 폴더의 `index.html`, `sw.js`, `manifest.webmanifest`, `icon.svg`, `README.md`, `build.py`, `src` 폴더 업로드 (Add file → Upload files, 폴더째 끌어다 놓기)
3. Settings → Pages → Branch: `main` / `(root)` → Save
4. 1~2분 뒤 `https://kittycong.github.io/il-hub/` 접속
5. 휴대폰: 위 주소를 열고 "홈 화면에 추가"

## 데이터
- 모든 데이터는 **이 브라우저의 localStorage**에만 저장됩니다. 엑셀 파일도 브라우저 안에서만 읽고 외부로 보내지 않습니다.
- 기기를 옮길 때는 설정·백업 → 백업 파일 저장 → 다른 기기에서 가져오기.
- 주민등록번호는 저장하지 않습니다.

## 앱 데이터 연동 (읽기 전용)
- 허브를 반드시 `kittycong.github.io/il-hub/` 에 배포하세요. 같은 도메인이라 휴가 대시보드(`guro_huga`)·생일 관리(`birth_guro1`)가 이 브라우저에 저장한 데이터를 허브가 바로 읽습니다.
- 휴가: 이 브라우저의 최신 작업본 → 공유 데이터 `guro_huga/data/app-data.json` 순으로 읽습니다. Supabase에만 저장했다면 휴가 앱에서 "공유 저장"을 한 번 해 주세요.
- 생일: 생일 앱에 저장된 명단 → 없으면 앱의 기본 명단.
- 토큰·관리자 비밀번호 키는 읽지 않고, 다른 앱의 데이터를 수정하지 않습니다.

## 원본 코드 고치기
- 실제 코드는 `src/` 폴더에 나뉘어 있습니다 (`hodata.js` = 업무 절차·마감, `data.js` = 기본 일정·앱 목록, `docs*.js` = 문서 서식 등).
- 고친 뒤 이 폴더에서 `python3 build.py` → `index.html`이 새로 만들어집니다. `index.html`만 다시 올리면 반영됩니다.
- 화면에서 고친 절차·날짜는 브라우저에 저장되므로 코드를 고치지 않아도 됩니다. 기기를 옮길 땐 백업 파일을 쓰세요.
