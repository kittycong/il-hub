# 웹앱 화면 규칙 (모든 채팅·코딩 공통)

웹앱 화면을 만들거나 손볼 때 아래 규칙을 **항상** 지킨다. 엑셀 내보내기·가져오기는 `excel-formula-io` 스킬을 함께 따른다.

## 1. 숫자는 무조건 1,000 단위 콤마
- 화면에 보이는 금액·수량·인원·시간은 모두 `1,234,567` 형태. (`toLocaleString()` 또는 공통 `money()` 함수)
- **입력칸도 콤마로 보인다.** `type="number"`는 콤마를 못 보여 주므로 글자칸(`inputmode="numeric"`)으로 바꾸고, 값을 읽을 때만 콤마를 뺀다. 입력 중에도 커서 위치를 지키며 콤마를 다시 넣는다.
- 콤마를 넣지 않는 것: 연도(2026), 문서·차수 번호, 계정과목 코드(1113), 계좌·전화번호, 날짜.
- 숫자 칸은 오른쪽 정렬 + `font-variant-numeric: tabular-nums`.
- 음수·차이는 부호와 색으로: `+` 징수·초과 = 빨강, `−` 환급·부족 = 초록 또는 빨강(뜻에 맞게), 일치 = `✓ 일치`.

## 2. 한 화면, 글씨 잘림 없음
- 데이터 칸에 `text-overflow: ellipsis`·`overflow: hidden` 금지. 긴 글은 줄바꿈(`word-break: keep-all`).
- 표 안 입력칸은 **들어 있는 값 길이만큼 최소 너비**(숫자 1칸 ≈ 1ch, 한글 ≈ 2ch)를 준다 → 큰 금액이 잘리지 않는다.
- **1280px 폭 화면에서 가로 스크롤 없이** 표가 들어오게 짠다. 넘치면 순서대로:
  1) 비슷한 열 합치기(관/항/목/세목 → 한 칸 "관 › 항 / 목 · 세목", 코드는 작은 글씨로 앞에)
  2) 한 칸에 두 줄(위 근로자분 / 아래 사업자분, 설명은 작은 회색 글씨)
  3) 패딩·글자 크기 조금 줄이기(표 11.5~12px)
  4) 그래도 넘치면 `.table-scroll` 안에서만 가로 스크롤 (페이지 전체 가로 스크롤은 금지)
- 헤더(`th`)는 짧게. 긴 설명은 `<br>` 아래 작은 글씨나 `title` 툴팁, 표 아래 `tfoot` 주석으로.

## 3. 한눈에 보기 · 작성·정산 확인
- 화면 맨 위에 **핵심 숫자 3~5개**(타일) 또는 **한눈에 보기 표**(재원·사람별 한 줄씩 + 합계 줄).
- 합계 줄은 항상 넣고, 다른 자료와 맞춰야 하는 값은 **검증 칸**으로: `✓ 같음` / `✗ 차이 12,000`.
  예) 13개 재원 합계 = 센터 전체, 집행계획 합계 = 교부 누계, 예수금 = 고지액.
- 이름을 누르면 상세(달별 내역)가 펼쳐지게: 기본은 접어서 한 화면 유지.
- 값의 출처를 작게 적는다(실제 급여베이스 / 계산 / 고지내역).
- 색 규칙: **분홍 = 입력, 노랑 = 확인, 초록 = 결과물**.

## 4. 문서(hwpx·공문·교부신청서 등) 생성 → 미리보기 먼저
- 문서를 만들면 **바로 저장하지 말고 미리보기 창**을 띄운다. 미리보기는 **실제로 만든 파일을 그대로 읽어** 그린다(hwpx면 `Contents/section*.xml`의 문단·표·셀 병합·정렬·굵기).
- 미리보기 창: 파일 이름, 여러 건이면 탭, `내려받기` / `N건 모두 받기`, "다음부터 미리보기 없이 받기" 선택.
- 작성 화면에는 저장 없이 볼 수 있는 `미리보기` 버튼. 보관함(만든 문서 목록)에도 `미리보기` 버튼.

## 5. 메뉴 맨 위 "작업 순서" 그림 설명서
- 문서·업무 메뉴마다 맨 위에 접을 수 있는 설명서:
  번호 단계 상자 → 화살표 → … (각 상자: 굵은 제목 + 한 줄 설명, 입력·확인·결과물 색), 그 아래 `만들어지는 것:` 알약, `💡` 주의 한 줄.
- 4~7단계, 한 줄 설명은 15자 안팎. 자세한 방법은 아래 접기(`details`)로 따로.
- 접힘 상태는 기기별로 기억(동기화 키와 섞지 않기).

## 6. 개인정보
- 주민등록번호·계좌번호·주소·비밀번호·아이디는 저장소·코드·화면 예시에 넣지 않는다. 받은 원본 파일은 고치지 않는다.

## 7. 끝내기 전 점검 (Playwright)
1. 1280px·1440px 폭으로 해당 메뉴 스크린샷을 찍어 본다.
2. 잘림 탐지: 보이는 요소 중 `overflow hidden/ellipsis`이면서 `scrollWidth > clientWidth`, 입력칸 `scrollWidth > clientWidth`, 페이지 `scrollWidth > innerWidth` → 0개여야 한다.
3. 콤마 탐지: 화면 글자에서 콤마 없는 4자리 이상 숫자 → 연도·코드·번호 말고는 0개.
4. 문서 버튼을 눌러 미리보기 창이 뜨고, 내려받은 파일이 미리보기와 같은지.
5. 콘솔 오류 0개.

## 참고 구현 (구로IL 문서웹앱 `index.html`)
- 입력칸 콤마: `numcify()` — `type=number`를 글자칸으로 바꾸고 그 칸의 `.value` getter가 콤마 뺀 값을 돌려줌(기존 계산 코드 수정 불필요), `MutationObserver`로 새로 그린 칸도 적용. 제외: `data-nocomma`, id에 Year/Seq/No.
- 표 입력칸 너비: `fitInputW()`.
- hwpx 미리보기: `hwpxPreviewHtml(blob)`, `hxOpen(items)`, `saveBlob()`에서 `.hwpx`를 가로채 미리보기.
- 작업 순서 설명서: `DOC_GUIDES` + `docGuideRender()`.
- 한눈에 보기 표 예: 예산 `bgOverviewHtml()`, 퇴직정산 `slRender()`.
